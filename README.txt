AAROGYA SURGICAL HOUSE — Installable Web App (PWA)

This package is an installable web app, not a signed Android APK.

1. Upload all four files (index.html, manifest.webmanifest, service-worker.js, icon.svg)
   to the root of your GitHub repository. Keep the filenames exactly as shown.
2. In GitHub, open Settings > Pages and enable deployment from your main branch / root folder.
3. Wait for GitHub Pages to publish the site. Open the published HTTPS URL in Chrome on Android.
4. Chrome menu (⋮) > Install app / Add to Home screen.

Important:
- A browser-installable PWA is the quickest install path. It does not require Play Store.
- Data is stored in the browser on that device. Use the in-app Backup regularly.
- This package does not create a signed .apk. A native APK needs an Android build/signing step.
